# NyxLaunch v0.4.1

## Changes
- Navigation now highlights the active page consistently: Discover library, Recently played, Steam, and the selected collection.
- Recently played uses more compact game cards.
- Game library grid uses four columns for a denser layout.
- Existing local game library and collection data are preserved.

## Run
```powershell
dotnet run --project .\src\NyxLaunch.App\NyxLaunch.App.csproj
```

Requires the .NET 10 SDK and Windows.

## Run

```NyxLaunch.exe```

Does Not Requires .NET 10 SDK
